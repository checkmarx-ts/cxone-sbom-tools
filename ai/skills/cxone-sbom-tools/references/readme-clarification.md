# Clarification of README.md

* The `README.md` is a file typically displayed in the repository home page
  for human consumption.
* Any references it contains to release artifacts are found in the repository.
* If a user asks for a released artifact (such as the PDF), direct them to the
  `releases` in the Github repository.
* Locations of artifacts should not be obtained from `README.md`.
* Methods of obtaining artifacts (e.g. `pip install ...`) found in `README.md` are valid
  but must use valid location references supplied by other references found in this
  skill.
* `cxone-sbom-tools` is the name of the project and repository containing the CLI
  of the same name and the Python module `cxone_sbom`.
* The module name `cxone_sbom` can be used for PEP 508 purposes.
